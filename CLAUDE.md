# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

**Justinus** is a personal philosophy notes website — a static documentation site for notes on classical and contemporary philosophers (Stoicism, Buddhism, Existentialism). Hosted on GitHub Pages at `https://jumarin22.github.io/justinus/`.

Built with **Docusaurus 3.9.2**, TypeScript, React, and MDX. Node.js >= 20 required.

## Commands

```bash
npm start          # Local dev server with hot reload
npm run build      # Build static output to /build
npm run serve      # Serve the built site locally
npm run typecheck  # TypeScript type checking
npm run deploy     # Deploy to GitHub Pages
npm run clear      # Clear Docusaurus cache
```

## Architecture

### Content (`/docs`)
Markdown/MDX files auto-organized into the sidebar by directory structure. Philosopher notes live here, grouped by tradition (`stoicism/`, `buddhism/`, `existentialism/`), then by philosopher, then by work.

Sidebar is auto-generated from the `/docs` directory (`sidebars.ts` uses `autogenerated`). The sidebar order follows file/folder naming conventions — use numeric prefixes if ordering matters.

Each folder has a `_category_.json` that sets the sidebar label, position, collapsed state, and links to its `index` doc. Always create one when adding a new folder.

#### Philosopher page pattern
- Philosopher root: `index.mdx` using the `<PhilosopherPage>` component (name, dates, descriptor, works list, links)
- Work root: `index.md` with title, translation credit, and overview content
- Book index: `index.md` with a thematic summary in a `<details open>` block (see below)
- Chapter files: named `{work}-book-{N}-chapter-{N}.md`, `sidebar_position` starting at 2 (index is 1)

#### AI summary convention
Each chapter and book index includes an AI-generated summary in this format:

```mdx
<details open>
<summary>Sonnet 4.6 Summary</summary>

## Sonnet 4.6 Summary

...summary content...

</details>
```

The label `Sonnet 4.6 Summary` reflects the model that generated it. Use the actual model name when generating new summaries.

#### Translation sources
Primary texts use public domain translations (e.g., Matheson 1916 for Epictetus). Always credit translator and edition at the top of the work index.

### Blog (`/blog`)
Published at `/journal` route. Author metadata in `authors.yml`, tags in `tags.yml`. Dated entries (`blog/20*.md`) are gitignored (personal content not committed).

### Custom Components (`/src`)
- `HomepageFeatures/` — Feature cards on the homepage
- `PhilosopherPage/` — Reusable philosopher profile page template
- `WorkDetail/` — Detail view for individual works

### Styling (`/src/css/custom.css`)
Custom Docusaurus theme overrides. Dark mode is default (`defaultMode: 'dark'` in config).

### Configuration
- `docusaurus.config.ts` — Main config: site metadata, navbar, theme, blog route alias
- `sidebars.ts` — Sidebar definition (auto-generated from `/docs`)

## Content Not Committed

- `blog/20*.md` — personal journal entries (gitignored)
- `*.txt` in `/docs` — scratch/reference files (gitignored)
- Python helper scripts (e.g., `add_summaries_b1.py`) may exist locally in `/docs` subdirectories for batch content generation but are not tracked

## Deployment

GitHub Actions (`/.github/workflows/deploy.yml`) deploys automatically on push to `master` — builds with `npm run build` and pushes to GitHub Pages.

Base URL is `/justinus/` — all internal links must be relative or account for this subpath.
